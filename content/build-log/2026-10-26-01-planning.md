title: 'Planning: brief, rules and a forgotten GitHub'
date: 2026-10-26
---

I started with a written brief (`docs/BRIEF.md`) and no code. The first prompt asked Claude Code for a short `CLAUDE.md`: what the site is, a confidentiality rule, "use only metrics that appear in `content/`", and placeholder commands.

**What went wrong:** the prompt pointed at `docs/BRIEF.md`, but the file was still called `website-BRIEF.md`. Claude used the file that existed and said so instead of guessing.

**The GitHub dig:** I asked Claude to go through my public repos for forgotten work. The find was a Dynamo-style replicated key-value store from grad school, a prequel to the replication work I do now. It also noticed that my `username.github.io` root was serving a personal page, which ruled out deploying there.

**Planning:** Claude asked the open questions first (framework, domain, host), then showed three visual directions as ASCII mockups. I picked Astro, GitHub Pages and the "engineering blueprint" look, and it wrote `docs/ARCHITECTURE.md` and `docs/PLAN.md` as small milestones.

**Lesson:** asking for questions *before* proposals gave a plan I didn't have to rewrite.
