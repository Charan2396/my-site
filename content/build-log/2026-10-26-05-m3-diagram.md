The home page hero is now the pipeline: Source → Queue → Process → Store → Consume, as numbered blueprint boxes with arrows. Each stage links to its story once one exists. Until then it says "Story coming soon" instead of linking to a page that isn't there.

**Change of plan:** the architecture said SVG. Claude built it as a plain HTML ordered list with CSS arrows instead: it reflows from a row to a column on phones with one media query, and screen readers announce it as a five-step list for free.

**Checked:** a throwaway test story and a draft were used to check the story template and that drafts stay hidden, then deleted before committing. No sideways scroll at phone, tablet or desktop widths, in either theme.
