A static Astro site in an engineering-blueprint style: grid paper, numbered boxes and figure captions. The home page is a data pipeline. The record view follows one invented order line through every stage, and the incident replay shows that pipeline break on one bad message and recover. Everything renders as plain HTML first, and the interactive parts are added on top with a little JavaScript.

I am building it with Claude Code, and the [build log](../build-log/) records each step, mistakes included.
